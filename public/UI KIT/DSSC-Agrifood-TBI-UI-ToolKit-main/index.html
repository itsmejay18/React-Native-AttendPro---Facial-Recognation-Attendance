DSSC Ready To Use Agri-Food UI Kit
Standalone Static Package

Reusable HTML, CSS, and JS starter for the DSSC TBI system.

This folder works like a lightweight AdminLTE-style base for your project. It includes an admin dashboard shell, a public landing page, and a component reference page using only plain static files.

What this package is for

  • Copy the folder into another project and start from the ready-made UI.
  • Use it as a design reference before rebuilding screens in Laravel, React, or plain PHP.
  • Keep the project’s look separate from backend code, similar to a starter theme.
